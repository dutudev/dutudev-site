# Astrodeck


# Asteroids but Roguelike

The classic Asteroids with Balatro elements, shoot asteroids, buy power-ups for your ship and escape by entering the anchor point

# Features

-   Asteroids base mechanics
-   Balatro-like shops and power-ups
-   Random events
-   Interactive enemies
-   Great soundtrack (by Jay)

# Credits

Game made by dutudev using godot
