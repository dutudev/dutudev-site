# Cubix

A game where you need to memorize a structure and then rebuild it as fast and as correctly as you can within the time limit. This project was made for the 6th edition of Unihack in collaboration with Sofia Pacurari, Eliza Negret, and Razvan Vitan.

**Controls**

left click - build

right click - pan

scroll - zoom

1, 2, 3, r - change shape and remove mode
